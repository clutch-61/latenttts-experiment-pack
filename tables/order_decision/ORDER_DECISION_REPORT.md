# Order-Decision Test：让「顺序感知」成为唯一可用信号

日期：2026-10-16 晚（承接三项可比性检查；**2026-10-17 五种子修订**）
脚本：`scripts/order_decision_test.py` + `scripts/order_decision_paired.py` + `scripts/run_order_decision_all.sh` + `scripts/run_order_decision_seeds.sh`
数据：`results/full/order_decision/`（单 seed 表 + **`order_decision_{summary,paired}_5seed.tsv`**，破坏 seeds 42–46）

---

## 0. 动机

三项检查得出：O2 的 order/hierarchy 机制优势**始终没转化**为 BoN top-1 收益。原因分析是——真实生成池里候选**对错由答案抽取判定**，scorer 只需在**已经正确的**轨迹间排序，**不需要**顺序感知。

本实验构造**顺序感知成为唯一可用判据**的条件，直接检验：这个机制优势到底能不能变成下游决策力？

## 1. 池构造（受控）

对每条 `corrects=1` 的验证轨迹（valid-64，抽 1000 条）造一个池：
- 候选 0：**原序（intact）**轨迹；
- 候选 1..N−1：对**同一条**轨迹做置换破坏（`adjacent_swap` / `segment_swap` / `multi_segment` / `full_reverse` / `mixed`）。

所有候选**内容相同、答案标签相同**（同一 trajectory 的置换），因此答案抽取 / 内容统计**无法**区分；**唯一可用的线索是时间顺序**。

指标（位置无关，与 `order_pair_acc` 同源）：
- **`pair_acc`** = 平均每对 (intact, corrupt) 上 `P(s_intact > s_corrupt) + 0.5·tie`；**0.5 = 顺序盲**。
- **`strict_win`** = intact 分数**严格高于所有**破坏候选的池比例；**chance = 1/N**。
- `tie_frac` = 池内全并列比例（置换不变聚合会给完全相同分数）。

破坏种子确定性 → 四个模型吃**完全相同的池**，可做**跨模型配对检验**。

## 3. 判读（关键，含两点诚实修正）

**结论 A（机制优势可转化，条件明确）：** 当顺序感知是唯一可用判据时，**O2 的机制优势首次转化为决定性的下游决策力**——`strict_win@N16` 在 adjacent/segment/full_reverse 达 **0.92–1.00**（chance 6.25%），`pair_acc` 0.92–1.00。SWIFT 基本**卡在 0.5 且大量并列**（置换不变聚合），HSRM 约 0.5（`full_reverse` 甚至 0.382 < 0.5，被序反向误导）。→ 「顺序感知」的价值**真实存在**，只是**任务相关**。

**结论 B（优势来源主要是表征/骨干，不全是损失）：** **B0（纯 CE、无 order-pref）同样高**（`strict_win@N16` adjacent 0.30、segment 0.76、full 0.97）。即 **「吃整条 token 轨迹 + 因果注意力 GPT-2」本身就带来强顺序感知**；SWIFT/HSRM 的顺序盲**源于其置换不变的潜步聚合**，而非「方法弱」。这与检查 1「表征/骨干严重不对齐」的判定一致。

**结论 C（order-pref 损失的净增量）：** 在同样表征/骨干下，**O2 稳定高于 B0**（adjacent +0.20、mixed +0.085，CI 排除 0；strict_win@N16 adjacent 0.957 vs 0.299）。→ order-pref 损失**确实**在机制轴上加了可测的正增量，且这次**转化**成了决策力。

**诚实边界（不要过度解读）：**
- 这是**合成诊断任务**（同轨迹置换的「轨迹有效性」判别），**不是 GSM8K 推理准确率**；不能推出真实 BoN top-1 会涨。
- 1000/7021 条正确轨迹；**已扩到 5 破坏 seed（42–46）**，见 `order_decision_{summary,paired}_5seed.tsv`——方向与单 seed 一致，方差极小（adjacent O2 pair_acc 0.9888±0.0007 / strict_win 0.9564±0.0005）。
- `multi_segment` 上 O2/B0 都不高（strict_win 0.05）——三块重排后可辨识度低，两者**没有**拉开差距。
- B1（BCE，同 GPT-2）缺失，无法把「CE vs BCE vs BCE+order」三者完整分离（B1 checkpoint 已删）。

## 4. 对论文叙事的含义

1. **不应**写成「O2 top-1 更强」——真实 BoN 上不成立。
2. **可以**写成：O2 的顺序敏感是可测、可复现的**机制优势**；其**变现条件**是「决策必须依赖轨迹顺序」——本实验给出该条件下的实证（+0.2~+0.6 pair_acc，strict_win 0.30→0.96）。
3. 「轻量 scorer 追平 O2」应表述为**廉价、置换不变的推理期打分器**在**对错由答案判定**的常规 BoN 上足够用；一旦顺序成为判据即失效。
