# O2 advantage slices（先验检验，5-seed 同池）

切片定义只用 gold / 基线 scorer；不用 O2 分数。  
主比较：GSM8K-Test N=16，种子 42–46 题级平均后配对 bootstrap（10000）。

产物：`diff_in_diff.tsv`、`baseline_error_correction.tsv`、`symmetric_rescue.tsv`、`p2_expanded_proxy.tsv`。

---

## 1. 差中之差（主检验）

预期：若顺序偏好契合续训候选结构，则 `(O2−C)_p2 − (O2−C)_frozen` 在 Top1 / `auc_cw` 上为正。

| pair | metric | frozen gap | p2 gap | DiD | 95% CI | n | 判定 |
|------|--------|----------:|-------:|----:|--------|--:|------|
| O2−SWIFT | top1 | +0.03 | +0.05 | **+0.02** | [−1.18, +1.20] | 1319 | 不支持 |
| O2−SWIFT | auc_cw | +2.34 | +3.19 | **+0.73** | [−1.76, +3.22] | 504 | 方向对，CI 跨 0 |
| O2−HSRM | top1 | +0.12 | −0.14 | **−0.26** | [−1.40, +0.85] | 1319 | 不支持 |
| O2−HSRM | auc_cw | +1.45 | +2.70 | **+1.35** | [−1.19, +3.93] | 504 | 方向对，CI 跨 0 |
| O2−B0 | top1 | +1.00 | +1.49 | **+0.49** | [−0.50, +1.50] | 1319 | 方向对，CI 跨 0 |
| O2−B0 | auc_cw | +2.21 | +2.62 | **−0.72** | [−2.98, +1.61] | 504 | 不支持扩大 |

**读数：** 池内 `auc_cw`（O2−SWIFT）冻/p2 各自显著（见既有 `paired_ranking_crossseed_pairs.tsv`），但 **交互项不显著**——不能写「优势在 p2 池里更明显」。Top1 对 SWIFT/HSRM 的 DiD 接近 0。

## 2. 基线排错题纠错（须看对称）

| 池 | 方向 | n | 救援率 | 读数 |
|----|------|--:|-------:|------|
| frozen | SWIFT 错 → O2 对 | 203 | 24.1% | |
| frozen | O2 错 → SWIFT 对 | 216 | 25.8% | **对称** |
| frozen | 多数票不一致 | 89 | O2-only 44 / SWIFT-only 45 | 平手 |
| p2 | SWIFT 错 → O2 对 | 212 | 25.8% | |
| p2 | O2 错 → SWIFT 对 | 216 | 26.4% | **对称** |
| p2 | 多数票不一致 | 93 | 44 / 49 | 略偏 SWIFT |
| p2 | B0 错 → O2 对 | 242 | 25.8% | |
| p2 | O2 错 → B0 对 | 216 | 18.6% | **不对称，偏 O2** |
| p2 | vs B0 不一致 | 73 | 49 / 24 | 偏 O2 |

窄间隔（基线 `margin_cw` 最低三分位）：O2−SWIFT Δ 约 +6pp，但同样需对称对照；全体题上 Top1 Δ≈0，说明窄间隔增益被「O2 错、SWIFT 对」抵消。

**读数：** 相对 SWIFT/HSRM，**没有**「O2 特别会纠基线错」的证据；相对 B0 的不对称与既有 O2−B0 Top1 优势一致。

## 定位（按用户纪律）

1. **可说：** O2 在 `auc_cw` 上相对 SWIFT（及 p2 上相对 HSRM）有池内辨别力优势；与 Top1 脱钩。  
2. **不可说：** p2 交互扩大 Top1/auc 优势；O2 在困难切片上稳定纠 SWIFT/HSRM。  
3. **相对 B0：** Top1 优势仍在；纠错不对称支持「补足 B0」，不是「全面胜过轻量 scorer」。  
4. **下一步（切面 3）：** 输入对等控制——否则无法判赢在目标还是输入信息量。
